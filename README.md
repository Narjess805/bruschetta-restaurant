# Bruschetta — Site Vitrine Restaurant Italien

##  Objectif
Site vitrine responsive pour un restaurant italien fictif, conçu pour démontrer mes compétences en intégration web front-end (HTML/CSS).

##  Mon rôle
- Conception du design (palette, typographie, structure)
- Développement HTML/CSS from scratch
- Mise en page responsive (mobile + desktop)
- Rédaction du contenu

##  Technologies
- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- Google Fonts (Georgia)

##  Fonctionnalités
- 3 pages : Accueil, Menu, Contact
- Design responsive (mobile / tablette / desktop)
- Navigation sticky
- Formulaire de réservation
- Palette italienne (vert profond + or)

##  Voir le site
Ouvrir `index.html` dans un navigateur.
